# Claude Code project instructions

@AGENTS.md

Claude Code must treat `AGENTS.md` as the mandatory operating policy for this repository.

Before changing code or assets:
- read `AGENTS.md` completely;
- read `docs/KNOWLEDGE_INDEX_v1.md`;
- follow the most specific project document for the current task;
- keep heavy runtime assets outside normal Git history;
- do not commit GGUF/model weights or raw AI-generation libraries;
- use feature branches and PRs rather than direct feature work on `main`.
